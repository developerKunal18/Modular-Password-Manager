# Modular Password Manager

A modular GUI password manager built using Python.

## Features
- Login system
- Modular architecture
- Save passwords
- Delete passwords
- Encoded storage

## Project Structure
- auth.py → authentication logic
- storage.py → file operations
- utils.py → helper functions
- app.py → GUI application

## Default Master Password
admin

## Technologies Used
- Python
- Tkinter
- base64 module

## How to Run
python app.py
